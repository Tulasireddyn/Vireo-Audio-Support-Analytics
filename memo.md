# One-page memo to Priya Raman

Vireo’s support data shows a clear and actionable pattern: the performance problem is concentrated in a small review cohort, not spread evenly across the support desk. The strongest, most defensible conclusion from the ticket pack is that the bottom agents are a genuine intervention target, but they should be reviewed within comparable cohorts rather than ranked by raw CSAT across all workstreams.

The first issue is dataset integrity. The legacy Freshdesk exports contained negative handle times because the migrated `resolved_at` values were reconstructed from UTC while the helpdesk displays in IST. Correcting this logic removed the false negatives and restored valid handle times. That is an important data-quality fix, not a cosmetic one: without it, an agent could be mis-scored as extremely fast or as a problem participant when the issue is actually in the data export.

The second issue is queue mix. Tier-2 warranty cases are intentionally harder than Tier-1 frontline work, and the policy explicitly says they should not be compared on volume metrics. In the audit, the worst-performing agents are clustered in the Escalations & Warranty team, where CSAT averages in the 2.4–2.8 range and replacement rates sit around 40–54%. That is materially worse than the frontline peer group, but it is also a queue-quality issue the policy anticipates.

The business cost is concentrated in replacements. Using the policy-defined formula of unit cost + ₹340 logistics, the total replacement spend across the dataset is ₹3.42 lakh over the 18-month period, or about ₹646k in the last full quarter. The bottom-10 review cohort accounts for roughly ₹299k of that three-month total, and a 15% reduction in their avoidable replacement rate would save about ₹45k per quarter. That is a concrete, policy-based estimate based on real replacement data, not a vague “improve CSAT” claim.

The recommended action is therefore targeted retraining, not blanket retraining. Prioritise the bottom review cohort within each comparable tier, and if budget remains, coach the four lowest-performing Tier-1 chat agents next. This keeps the Q3 budget focused on the people whose queue and process are creating the most avoidable cost, while avoiding a false signal from the warranty rota and the junk IVR transcripts that are system noise rather than agent performance.

The main caveat is causality: this estimate is directional. The data shows a strong correlation between poor agent performance, higher replacement rates, and lower CSAT in the review cohort, but it does not prove that retraining alone will create the full ₹45k saving. The value is still useful because it is grounded in the dataset, uses policy-defined cost logic, and is transparent about the uncertainty.
